# EXPERIMENTS_NEXT.md — Follow-Up Candidates

Filtered view of [`EXPERIMENTS.md`](EXPERIMENTS.md): only rows where the experiment was
**adopted**, or the table's own **"pursue further?"** call is **Yes** or **Maybe**. Same
format, same columns, same links — this file just drops everything that was killed or
not-adopted with no upside flagged. See `EXPERIMENTS.md` for the full 54-row picture,
including the ~28 rows omitted here.

**Shared frame.** Almost every experiment below is scored against the same reference
points, established early and reused verbatim:

- **The composite** (`experiments/largecap/README.md`): a no-fit, equal-weight blend of
  7 factor groups (18 factors) on a ≥$2B-market-cap, ≥$10M-dollar-volume, both-betas-observed
  universe. Universe IC 0.037 (t 1.9); its `lc_t10` long-short LP: gross IR 0.615, net IR
  0.541, 2025 net return −12.4%.
- **The pre-registered kill/pass rule** used by most `feat_*` and methodology experiments:
  KILL if the paired IC gain over the composite has t < 1 or the gain is confined to the
  smallest size tercile; PASS requires paired t ≥ 2 **and** Bonferroni-adjusted permutation
  p ≤ 0.05 **and** not small-tercile-only. Most experiments land in between (t between 1
  and 2) and are recorded as inconclusive, not killed or passed.
- **`pm_ablation`**: the diagnostic finding that every model's real-universe edge
  (rank IC ≈0.14–0.15) collapses to ≈0 once FIAM's tradeability screens (price ≥ $5,
  mcap ≥ $500M, sector caps, turnover cap) are applied — the edge lives in sub-$5,
  sub-$500M, mostly biotech short names.

**Reading the columns.** *Verdict* is the practical takeaway (would this be shipped/reused
today), not just the README's literal status token. *Pursue further?* is this table's own
judgment call, not a project decision — treat it as a prioritization hint.

### Legend

- **Killed** — failed the experiment's own pre-registered kill rule; not used.
- **Not adopted** — run to completion, result present but statistically inconclusive (t roughly 1–2, or a real-but-too-small effect); not used as-is.
- **Adopted** — met its bar and is (or should be) in active use / the current reference.
- **Diagnostic only** — no adopt/reject rule was ever defined; the experiment's value is the standing fact or methodology it established, not a signal to trade.
- **Blocked** — could not be run to its intended conclusion for lack of data (e.g. I/B/E/S analyst revisions, daily returns).
